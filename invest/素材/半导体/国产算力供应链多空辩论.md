# 国产算力供应链多空辩论

> 基于智谱AI 1GW国产数据中心事件，对核心标的进行多方/空方论据整理。数据来源：雪球社区研究帖。

---

## 一、寒武纪（SH688256）—— AI芯片稀缺标的

### 🟢 多方论据

1. **国产AI芯片最纯标的**：思元590/690覆盖云端训练+推理，是A股唯一纯正AI芯片公司。智谱GLM-5.2 Day 0完成适配，证明生态成熟度在提升
2. **政策红利**：国产算力替代是国家战略，政企客户必须采购国产芯片。1GW级数据中心落地验证了超大规模部署可行性
3. **公募重仓**：已进入公募基金前十大重仓股，傅鹏博、谢治宇等明星基金经理加仓
4. **业绩拐点**：2025年营收大幅增长，亏损收窄，2026年有望扭亏为盈

### 🔴 空方论据

1. **估值极高**：市值超3000亿，即使扭亏，PE仍超百倍。透支了未来3-5年业绩
2. **性能差距**：昇腾910B显存64GB/带宽1.6TB/s vs 英伟达H200 141GB/4.8TB/s，差距约2倍。训练效率仍有明显差距
3. **竞争激烈**：华为昇腾（政企首选）、海光DCU（兼容CUDA）、摩尔线程等8家国产芯片竞争，寒武纪并非唯一选择
4. **大股东减持**：2026年4-6月A股614家公司披露减持计划，科技股大股东"像逃难一样疯狂抛售"
5. **杠杆集中风险**：电子+通信仓位占比已达六成，一旦去杠杆，回调幅度可达40-60%

> [参考](https://xueqiu.com/5899108858/401546618) — 国产芯片与英伟达性能对比

**多空判断**：短期估值过高，长期赛道确定。适合等回调再介入，不宜追高。

## 二、海光信息（SH688041）—— CPU+DCU双轮驱动

### 🟢 多方论据

1. **兼容CUDA生态**：DCU芯片迁移成本低，这是最大的护城河。企业不需要重写代码就能切换
2. **"CPU+GPU+互联+服务器"集成能力**：国内稀缺的算力系统集成厂商，不只是卖芯片
3. **业绩高增**：2025年营收143.77亿元，信创+AI双驱动。CPU适配信创生态实现稳定批量出货
4. **智谱适配**：GLM-5.2 Day 0完成适配，政企客户可直接用国产算力跑国产模型
5. **机构加仓**：公募基金二季报显示大幅增持

### 🔴 空方论据

1. **CUDA兼容≠CUDA等价**：迁移成本低但性能仍有损耗，复杂算子适配仍需大量工作
2. **华为昇腾压制**：政企市场华为生态更成熟，海光在信创份额可能被挤压
3. **估值不低**：当前市值对应2025年业绩仍在50倍PE以上
4. **技术路线风险**：x86架构受AMD授权限制，长期自主可控性存疑

> [参考](https://xueqiu.com/9271268436/401560585) — 海光信息"CPU+DCU"双产品线协同

**多空判断**：CUDA兼容是真实护城河，但需警惕华为竞争。在国产芯片中确定性较高。

## 三、中科曙光（SH603019）—— 算力基建龙头

### 🟢 多方论据

1. **十万卡集群能力**：曙光8000"登峰"超节点首秀，全国产十万卡级AI超集群，技术壁垒高
2. **系统集成优势**：不只是卖服务器，而是提供从芯片到集群到运营的完整方案
3. **海光信息大股东**：持有海光信息股权，享受芯片+整机双重收益
4. **国家超算中心合作**：与无锡签署共建国家超算无锡中心协议，政企资源深厚
5. **WAIC展出真机**：华为vs曙光超节点对比，曙光做的是"十万卡级全域算力基建集群"

### 🔴 空方论据

1. **利润率低**：系统集成业务毛利率远低于芯片，赚钱靠走量
2. **客户集中**：高度依赖政企和运营商采购，受政策周期影响大
3. **竞争加剧**：浪潮信息、超聚变、拓维信息等都在抢国产算力整机市场
4. **估值已反映预期**：股价已从底部大幅反弹，短期空间有限

> [参考](https://xueqiu.com/5154446510/401483812) — 华为vs曙光超节点对比

**多空判断**：算力基建确定性高，但利润率是长期隐忧。适合作为算力主题的底仓配置。

## 四、浪潮信息（SZ000977）—— AI服务器龙头

### 🟢 多方论据

1. **国内AI服务器绝对龙头**：自有品牌AI服务器市占率第一，山东国资控股
2. **业绩爆发**：2026H1归母净利预计26-31亿元，大幅增长。AI硬件链业绩全面兑现
3. **全球份额领先**：全球AI服务器代工份额领先，最先兑现平台规模化交付红利
4. **适配新一代平台**：已完成英伟达Rubin平台方案适配，同时承接国内智算中心新建集群
5. **估值合理**：相比寒武纪，浪潮的PS估值更合理（行业中枢1.5x）

### 🔴 空方论据

1. **毛利率极低**：服务器整机是"搬砖"生意，毛利率仅10-15%，赚的是辛苦钱
2. **话语权弱**：上游芯片厂商（华为/英伟达）掌握定价权，服务器厂商利润被挤压
3. **周期性强**：算力投资有明显周期，capex下行时业绩可能断崖
4. **国产化转型阵痛**：从英伟达体系转向国产芯片体系，适配成本高

> [参考](https://xueqiu.com/1215457102/401535500) — 浪潮信息：国内AI服务器绝对龙头

**多空判断**：业绩确定性最高，但利润率是硬伤。适合稳健配置，不适合博高弹性。

## 五、中际旭创（SZ300308 / 03308.HK）—— 光模块全球龙头

### 🟢 多方论据

1. **全球龙头地位**：800G/1.6T光模块全球市占率第一，1.6T硅光芯片自研
2. **港股IPO验证**：募资550亿港元，基石投资者包括淡马锡、高瓴、贝莱德、阿里、腾讯，阵容堪称近年之最
3. **Q2出货量验证**：800G约260-270万只 + 1.6T约60万只，量价齐升
4. **公募头号重仓**：蝉联公募基金第一大重仓股，贵州茅台跌至第30位
5. **NPO趋势**：腾讯云Q4部署NPO近封装光学，光互连从概念走向落地

### 🔴 空方论据

1. **港股IPO稀释**：550亿港元募资，H股发行可能稀释A股股东权益
2. **估值争议**：50倍PE是否合理？光模块是周期性行业还是成长性行业？
3. **产能过剩风险**：800G向1.6T切换期间，旧产能可能面临价格战
4. **英伟达网络业务增速放缓**：有观点认为应盯英伟达网络业务增速而非GPU出货量，这才是"矿难预警机"
5. **贸易风险**：美国对中国光模块出口管制政策不确定

> [参考](https://xueqiu.com/1199484007/401518278) — 英伟达网络业务增速才是矿难预警机

**多空判断**：行业地位无可争议，但估值和港股IPO是短期压制因素。1.6T放量是下一个验证节点。

## 六、英维克（SZ002837）—— 液冷散热龙头

### 🟢 多方论据

1. **华为冷板式液冷核心供应商**：冷板+CDU全链条方案配套昇腾950，WAIC展出真机
2. **行业拐点已至**：AI芯片功耗突破75kW，风冷完全失效，全液冷从可选变为出厂标配
3. **市场规模爆发**：液冷行业2027年整体市场规模约2500亿元，2028年有望接近5000亿
4. **全方案覆盖**：风冷、冷板、浸没式全方案，头部智算中心核心供应商
5. **订单爆满**：台湾液冷公司订单爆满，大量下单给大陆精密件公司

### 🔴 空方论据

1. **竞争格局分散**：曙光数创、高澜股份、同飞股份等都在抢液冷市场，壁垒不够高
2. **客户集中风险**：高度依赖华为生态，如果华为切换供应商影响大
3. **利润率压力**：液冷系统集成毛利率不高，核心利润在冷板/CDU零部件
4. **市值小弹性大**：市值小意味着波动大，追高容易被套
5. **技术路线不确定**：冷板式 vs 浸没式，哪种方案最终胜出尚无定论

> [参考](https://xueqiu.com/5005661483/401545748) — 英维克液冷全链条方案详解

**多空判断**：液冷是确定性最强的增量赛道，但需精选个股。英维克绑定华为是优势也是风险。

---

## 七、工业富联（SH601138）—— 全球AI服务器ODM

### 🟢 多方论据

1. **全球AI服务器代工龙头**：承接英伟达GB200/GB300整机架代工，全球份额领先
2. **平台化优势**：同时服务海外（英伟达体系）和国内（国产芯片体系）客户
3. **业绩确定性**：全球AI服务器需求持续增长，订单可见度高
4. **估值合理**：相比纯国产算力标的，工业富联估值更理性

### 🔴 空方论据

1. **国产替代逻辑弱**：工业富联的优势在英伟达体系，国产化趋势反而可能削弱其份额
2. **利润率低**：代工模式毛利率仅8-12%，规模大但不赚钱
3. **鸿海背景**：台资背景在国内政企市场可能受限

**多空判断**：适合看全球AI服务器需求的投资者，但国产替代逻辑不如浪潮/曙光。

---

## 八、澜起科技（SH688008）—— 内存接口芯片

### 🟢 多方论据

1. **全球市占率领先**：内存接口芯片全球龙头，DDR5世代迭代直接受益
2. **AI数据中心拉动**：HBM/存储芯片短缺持续到2028年，价格至少上涨25%
3. **公募加仓**：进入明星基金经理新增重仓名单
4. **业绩高增**：数据中心业务收入大幅增长，带动整体毛利率提升

### 🔴 空方论据

1. **股东减持**：澜起科技股东一把减持30.58亿元
2. **客户集中**：高度依赖三星、SK海力士等存储大厂
3. **周期性风险**：存储芯片有3-4年供需周期，产能过剩时业绩可能大幅下滑

> [参考](https://xueqiu.com/5845933952/401543032) — 长鑫科技上市对存储板块的资金虹吸

**多空判断**：DDR5+AI双驱动，但需关注长鑫科技7/27上市带来的资金分流。

## 综合对比矩阵

| 标的 | 多方确定性 | 空方风险 | 估值合理度 | 建议策略 |
|------|-----------|---------|-----------|---------|
| 寒武纪 | ⭐⭐⭐ | ⭐⭐⭐⭐ | 偏贵 | 等回调，不追高 |
| 海光信息 | ⭐⭐⭐ | ⭐⭐ | 合理偏贵 | CUDA兼容是真护城河 |
| 中科曙光 | ⭐⭐⭐ | ⭐⭐ | 合理 | 底仓配置 |
| 浪潮信息 | ⭐⭐⭐ | ⭐⭐ | 合理 | 稳健选择 |
| 中际旭创 | ⭐⭐⭐⭐ | ⭐⭐ | 偏贵 | 等港股IPO落地 |
| 英维克 | ⭐⭐ | ⭐⭐⭐ | 合理 | 液冷赛道精选 |
| 工业富联 | ⭐⭐ | ⭐⭐ | 合理 | 全球视角配置 |
| 澜起科技 | ⭐⭐⭐ | ⭐⭐ | 合理 | 存储涨价受益 |

> [!tip] 核心结论
> 1. **最高确定性**：浪潮信息（业绩验证）+ 中际旭创（行业地位）
> 2. **最高弹性**：寒武纪（但估值风险也最大）
> 3. **最被低估**：海光信息（CUDA兼容护城河被低估）
> 4. **最佳赛道**：液冷（英维克）—— 从可选变为标配的拐点
> 5. **最大风险**：杠杆集中度（电子+通信仓位六成）+ 长鑫科技上市虹吸
