# Book Mirror — 书镜：个性化深度读书法

将一本书的内容映射到你的人生经历上，生成一份双栏对照的「脑页（Brain Page）」：左栏还原作者核心观点，右栏逐条拆解到你的个人经历。越读越懂自己。

## 核心理念

普通读书法：读完 → 写几条笔记 → 忘记。
书镜读书法：每个观点都映射到你的真实经历 → 知识内化 → 迭代沉淀。

AI 完整掌握你的知识库（卡片、闪念、日记、读书记录），在作者观点和你的生活之间建立精准连接。不是空泛的"这很有启发"，而是"这个观点对应你上周和某位创始人的真实对话"。

## 触发词

- `/book-mirror`
- "书镜"
- "读这本书"（提供 PDF/EPUB 文件路径时）
- "做书镜" + 书名

## 输入方式

支持三种输入：

| 输入 | 说明 |
|------|------|
| PDF/EPUB 文件路径 | 直接处理，先用 markitdown 提取全文 |
| 书名 | 在 `读书记录/` 中查找已有笔记作为起点 |
| URL | 先用 document-extractor 提取，再处理 |

## 执行流程

### Step 1：输入处理

根据输入类型执行：

**PDF/EPUB 文件**：
```bash
python3 -m markitdown "{文件路径}"
```
提取全文 Markdown，按章节标题（`#` 或 `##`）拆分为章节列表。
如果无明确章节标题，按内容分段（每段约 3000-5000 字）拆分。

**书名（已有笔记）**：
在 `读书记录/` 目录中搜索匹配文件（模糊匹配，如"认知觉醒"可匹配《认知觉醒：开启改变自己的原动力》）。
读取已有笔记内容，作为处理基础。如果笔记内容不足以支撑完整映射，提示用户提供 PDF/EPUB 文件。

**结果**：获得章节列表，每个章节包含标题和正文内容。

### Step 2：构建个人画像

这是书镜的核心。从你的知识库中构建一份结构化个人画像，作为后续所有映射的上下文。

**扫描范围**：
- `卡片/` — 1800+ 张知识卡片（核心知识结构）
- `private/Inbox.md` — 闪念（近期想法、情绪状态）
- `private/🎭 小胖素材库.md` — 写作人格素材（经历、观点、踩坑）
- `行思录/日复盘/` — 最近 7 天的日复盘（当前状态）
- `读书记录/` — 已读过的书（知识背景）
- `投资研究/` — 投资观点和策略
- `private/📋 任务看板.md` — 当前在做的事

**画像结构**（写入临时上下文，不生成文件）：

```markdown
## 个人画像

### 身份标签
[从内容中提取：创业者/开发者/投资者/内容创作者/...]

### 家庭与背景
[如有相关笔记/闪念提及]

### 职业经历
[从卡片、素材库中提取关键经历和成就]

### 当前关注
[从日复盘、任务看板中提取：最近在想什么、做什么]

### 核心观点与信念
[从卡片中提炼的持久认知：对投资/创业/学习/人生的立场]

### 情绪与内在
[从闪念、日记中提取的情绪模式和内在议题]

### 已读知识背景
[从读书记录中提取已读过的书和核心观点]
```

**实现策略**：
- 不需要读取全部 1800 张卡片。优先扫描：书名/关键词相关的卡片 + 最近修改的 30 张卡片 + 素材库 + 闪念 + 最近日复盘
- 画像控制在 2000 字以内，过长会挤占上下文窗口

### Step 3：识别迭代历史

检查是否读过同一本书：
- 在 `读书记录/书镜/` 中搜索同名文件
- 如果存在，读取上次的 Brain Page，提取已有的映射和洞察
- 标记为"迭代读"，新 Brain Page 将继承并扩展前次认知

### Step 4：逐章映射（核心步骤）

对每个章节启动子 agent 处理。章节间并行执行（使用 Agent 工具，设置 `run_in_background: true`）。

**每个子 agent 收到**：
1. 个人画像（Step 2 输出）
2. 本章标题和正文内容
3. 上次读此章的映射（如果是迭代读，Step 3 输出）
4. 章节序号

**子 agent 输出格式**（每个章节生成一个结构化片段）：

```markdown
### 第 N 章：[章节标题]

#### 作者核心观点
> 用 2-3 句话凝练本章最核心的思想，不是概括内容，而是提取"作者到底想说什么"。

#### 观点映射

| 作者观点 | 你的经历/关联 |
|---------|-------------|
| 观点 1 的精炼表述 | 你的具体经历（引用卡片/闪念/事件） |
| 观点 2 的精炼表述 | 对应你的哪段经历、哪个决定、哪种感受 |
| 观点 3 的精炼表述 | 这个观点如何改变你接下来会做的事 |

#### 深度链接
- [[相关卡片1]] — 一句话说明关联
- [[相关卡片2]] — 一句话说明关联
（如果书中观点与已有卡片产生强关联，列出 1-3 个）

#### 反思问题
1. [从本章观点引出的、针对你个人的尖锐问题]
2. [可选，不是每章都需要]
```

**映射质量要求**：
- 禁止空泛："这对创业者很有启发" → 必须落地到你的具体经历
- 禁止编造：必须基于知识库中可追溯的内容做映射
- 鼓励冲突：如果书中观点与你的实际信念有矛盾，明确标出
- 优先映射到最近经历（日复盘、闪念），这些是最鲜活的

### Step 5：生成 Brain Page

合并所有章节映射，生成完整的 Brain Page 文件。

**输出路径**：`读书记录/书镜/《书名》.md`

**文件结构**：

```yaml
---
tags:
  - 书镜
  - 读书笔记
title: 《书名》Brain Page
date: YYYY-MM-DD
lastmod: YYYY-MM-DD
author: 作者名
read_count: 1
---
```

```markdown
# 《书名》 Brain Page

> [!info] 书镜
> 本文将书中每一章的核心观点映射到我的个人经历。左栏是作者说了什么，右栏是我的人生。
> 生成日期：YYYY-MM-DD | 第 N 次读

## 书的概况
[2-3 句话：这本书讲什么、为什么值得读、适合什么样的人]

## 映射总览
[从所有章节映射中提炼 3-5 个贯穿全书的核心洞察，
以及它们如何在你的人生中交叉验证]

---

[Step 4 输出的所有章节映射，按章序排列]

---

## 全书反思

### 改变我的 3 件事
[不是"学到了什么"，而是"接下来会因此改变什么行为/决定/想法"]

### 与已有认知的碰撞
[书中哪些观点验证了你已有的信念？哪些推翻了？哪些让你看到了新的维度？]

### 下一步行动
- [ ] [具体的、可执行的行动]
- [ ] [具体的、可执行的行动]

### 值得新建的卡片
- [[卡片名]] — 为什么值得建
- [[卡片名]] — 为什么值得建
```

### Step 6：收录联动

处理完成后，自动执行以下联动：

1. **新建卡片**：将"值得新建的卡片"实际创建到 `卡片/` 目录，使用知识卡片模板
2. **任务看板**：将行动项写入 `private/📋 任务看板.md`
3. **选题库**：如果映射中产生了好的内容角度，收录到 `private/📋 选题库.md`
4. **更新读书记**：在 `读书记录/` 中更新或创建该书的读书笔记，添加"已有书镜"连接

### Step 7：输出结果

```
书镜完成

书名：《XXX》
章节数：N 章
映射数：N 条
深度链接：N 张已有卡片
新建卡片：N 张
行动项：N 条
迭代读：第 N 次
输出：读书记录/书镜/《XXX》.md
```

## 迭代读机制

第二次读同一本书时：
1. 自动检测 `读书记录/书镜/《书名》.md` 是否存在
2. 读取上次 Brain Page，提取已有映射
3. 子 agent 收到额外上下文："上次你读这章时，映射了这些经历..."
4. 新 Brain Page 追加"第 N 次读"标记，保留历史映射的价值
5. `read_count` + 1

迭代价值：
- 第二次读会继承第一次的全部认知
- 第 N 次读能贯通前 N-1 次所有思想脉络
- 你的知识库也在持续增长，新的卡片/闪念/日记会带来新的映射角度

## 注意事项

1. **个人画像质量决定映射质量**：如果画像构建太泛泛，映射会流于表面。宁可画像小而精，不要大而空
2. **章节数量控制**：如果书超过 30 章，建议先处理用户最感兴趣的章节，不要全部并行（上下文窗口限制）
3. **不编造经历**：所有映射必须基于知识库中实际存在的内容，找不到对应经历时写"暂无直接关联"，不要杜撰
4. **尊重冲突**：如果书中观点与用户已有信念矛盾，明确指出而不是回避
5. **双栏用表格**：Obsidian 表格在预览模式下双栏效果好，移动端也有基本可读性
6. **子 agent 并行上限**：同时不超过 10 个子 agent，超过则分批处理
