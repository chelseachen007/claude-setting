## 二、必踩的坑

### 1. 本机代理会让所有接口挂掉
```
urllib.request.build_opener(urllib.request.ProxyHandler({}))
```
不适用这个，东财直连接口全部超时或 502。本机配了 `http_proxy`。

### 2. 精度问题：f43 / f162 / f167 是 ×100 整数
兆易创新 244.45 元会返回 `24445`。PE 11.7 返回 `1170`。一律 `/100`。

### 3. `RPT_LICO_FN_CPD` 的 columns 有禁区
写了下面任一个就返回 `code: 9501, message: 返回字段参数不存在`：
- `NOTICE_DATE`
- `DEDUCT_PARENT_NETPROFIT`
- `OPERATE_INCOME`（要用 `TOTAL_OPERATE_INCOME`）

**安全的 columns**：
```
SECURITY_CODE,SECURITY_NAME_ABBR,TOTAL_OPERATE_INCOME,YSTZ,PARENT_NETPROFIT,SJLTZ,XSMLL,BOARD_NAME,REPORTDATE
```

### 4. 报表类接口的 filter 语法不同
`RPT_DMSK_FN_CASHFLOW` / `RPT_DMSK_FN_BALANCE` 要用：
```
filter=(REPORT_DATE='2026-09-30 00:00:00')
```
不是 `REPORTDATE`（会报「REPORTDATE列不存在」）。而且**必须先给 columns**，不给会报「返回字段参数不能为空」。

### 5. 不可用的源
- `searchapi.10jqka.com.cn`（同花顺）— DNS 解析失败
- 腾讯 `qt.gtimg.cn` — 能用，但需要 `ProxyHandler({})`，且 `f39`（PE）已失真、`f47/f48`（52周高低）不可信

### 6. `push2his` 的板块接口会整段失效（2026-11-12 实测）
`push2his.eastmoney.com/api/qt/stock/kline/get`（板块日K）和 `.../fflow/daykline/get`（板块资金流）对**任意**板块代码都返回 `Remote end closed connection without response`，连续 30 分钟以上。

- 试过：4 个板块 × 3 次重试 × 4 个周期（20/60/120/250 天）全挂；`fflow` 试了 7 个不同 BK 代码全挂
- **但 `push2.eastmoney.com/api/qt/clist/get`（板块列表）同时段正常**
- 结论：失效的是 `push2his` 这一路子域名，不是板块接口本身。**遇到这种情况不要以为是代码写错或 BK 代码给错**
- **补充（同日晚实测）：`push2` 和 `push2his` 是分别限流的，且都会挂。** `push2` 拉 1049 个板块码时正常，几分钟后 `clist`/`stock/get` 也一起 RST，50 秒静默后自愈；`push2his` 则整个下午到晚上一直挂。`datacenter-web.eastmoney.com`（财报）全程正常
- **探活顺序**：先单发 1 个请求（`retries=1, timeout=15`）确认哪个子域名活着，再决定走哪条路。反复重试只会让限流窗口一直续期
- 绕过：用数据湖 `daily_bars_adj` + `industry_members` 聚合个股算板块涨跌（自算口径，见第四节）

### 7. `_get()` 的重试反而会拖死脚本
`_get(url, retries=3)` 每次失败后 `sleep(1.5 * (i+1))`，而 `OPENER.open(timeout=60)`。上游直接 RST 的时候每个请求不是快速失败，**单次最长挂 60 秒**，3 次重试 = 最坏 190 秒/请求。

2026-11-12 拉 5 个板块的日K，脚本跑了 **10 分钟**才全挂。所以：
- 批量拉板块时，先用**一个**请求探活，探不通直接换路，不要循环
- 需要批量时把 `retries` 降到 1，或 `timeout` 降到 15

### 8. 板块代码必须用 `BKxxxx` 数字码，中文名不在内置表里就是错的
**已修复（2026-11-12 晚）**：内置表已从 21 个扩到东财全量 **1049 个（行业 495 + 概念 554）**，并加了 `_bk()` 解析器——未命中不再静默返回空值，而是抛 `KeyError` 并列出相近名。下面是当时踩坑的原始记录。

老版本 `BOARDS` 只有 21 个键（通信设备、半导体、CPO、算力……都是 2026 年热门的科技/医药方向），**房地产、银行、水泥、建材全部不在表里**。

`board_kline("房地产开发")` / `board_flow("水泥")` 这类调用**会静默失败或报 `'NoneType' object is not subscriptable`**，看起来像接口坏了，其实是名字没映射上。

正确做法：先用 clist 拿 ID
```python
url = ("https://push2.eastmoney.com/api/qt/clist/get?"
       "pn=1&pz=500&po=1&np=1&fltt=2&invt=2&fid=f62&fs=m:90+t:2&fields=f12,f14")
# f12=板块代码 f14=板块名称
```
2026-11-12 实测映射（部分）：

| 名称 | 代码 | 名称 | 代码 |
|---|---|---|---|
| 房地产Ⅱ | BK0451 | 银行Ⅱ | **BK0475** |
| 房屋建设Ⅱ | BK1246 | 银行 | BK1283 |
| 房屋建设Ⅲ | BK1470 | 国有大型银行Ⅲ | BK1611 |
| 装修建材 | BK1019 | 股份制银行Ⅲ | BK1610 |
| 水泥 | **BK0424** | 水泥制造 | BK1464 |
| 装修装饰Ⅱ | BK0725 | 沪深A股 | BK0740 |

**注意 `pz=500` 只返回 100 条，东财行业实际有 496 个**，要找的板块可能不在前 100 里。必须分页（`pn` 从 1 递增，空页停）。

**现在不用自己记了**：
```bash
.venv/bin/python3 工具/抓数/fetch_eastmoney.py boards 水泥      # 模糊搜
.venv/bin/python3 工具/抓数/fetch_eastmoney.py boards --all     # 全量 1049
.venv/bin/python3 工具/抓数/fetch_eastmoney.py boards --refresh # 重拉东财比对差异
```
库里 `board_kline()` / `board_flow()` 直接传中文名即可，`_bk()` 会解析；传 `bk0424` 这种小写也认。

### 9. `SJLTZ` 算加权同比会严重失真
`SJLTZ` 是**同比增速**，很多人会按 `PARENT_NETPROFIT` 加权求平均。这是错的：
- 万科 2026Q3 `SJLTZ=+14.5%` 但归母 **-239 亿**（低基数导致增速为正、绝对额巨亏）
- 按净利加权后，地产链加权同比 +4.0%，而中位数是 **-13.4%**，差了 17 个百分点

**规则**：`SJLTZ` / `YSTZ` 一律用**中位数**，不用加权平均。要加权就用 `PARENT_NETPROFIT` 绝对值算总量增速（Σ本期 / Σ上期 - 1），不要混着用。

## 三、字段速查

### 个股 `fields`
| 字段 | 含义 | 处理 |
|---|---|---|
| f43 | 现价 | /100（已确认，无浮点，需 /100.0 且要 float） |
| f57 | 代码 | 直接用 |
| f58 | 名称 | 直接用 |
| f116 | 总市值（元） | /1e8 得亿 |
| f162 | 静态 PE | /100 |
| f167 | PB | /100 |
| f168 | 换手率 | /100 |
| f170 | 涨跌幅 | /100 |

### 财报 `RPT_LICO_FN_CPD`
| 字段 | 含义 |
|---|---|
| `TOTAL_OPERATE_INCOME` | 营业总收入（元） |
| `YSTZ` | **累计**营收同比（%） |
| `PARENT_NETPROFIT` | 归母净利润（元） |
| `SJLTZ` | 归母净利同比（%） |
| `XSMLL` | 销售毛利率（累计口径，%） |
| `BOARD_NAME` | 东财行业分类 |

**重要**：`YSTZ` / `SJLTZ` / `XSMLL` 都是**累计值**，不是单季。要算单季毛利率得拿两期数据相减：
```
单季毛利率 = (Q3累计营收 × Q3累计毛利率 − H1营收 × H1毛利率) / (Q3营收 − H1营收)
```
**这个公式在营收环比下滑时会失真**（分母可能变小甚至为负），使用时要注意。

## 四、口径纪律

- **PE 必须标口径**。静态 PE（去年年报）vs TTM 在利润爆发年能差 3 倍
- **板块指数自算涨跌要注明**，不能和申万/同花顺的数字混着用
- **资金流单位**是元，要 /1e8 换算成亿
- **当日盘中数据 vs 收盘数据**差 ±0.1~0.5，报告里要标「盘中」
