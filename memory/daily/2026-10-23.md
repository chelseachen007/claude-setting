
## 知识库治理：停用死流程 + 雪球日报三问改造

**背景**：用户指出「不流程化」——雪球日报每天生成但从不看，对投资决策零帮助。

### 第 3 项：关掉死流程（已完成）
- 停用 `ob-insights` + `source-command-obinsights`，移到 `.agents/skills-disabled/`（可逆）
- 判断标准：**流程类 skill**（有固定节奏、产出到固定目录）会死；**工具类 skill**（md-to-pdf、card-caster）不算死，只是待调用
- 洞察报告 5 个月零产出，且产出从未转化为决策或文章

### 第 5 项：雪球日报首屏改造（已完成）
- 新建 `投资研究/触发器清单.md`，从投资日记 10-15/10-19 两条抽出 T1-T7
- `xueqiu_score.py` 新增 `scan_three_questions()`，输出关注池命中 + 触发器命中 + 连续 0 命中天数
- **关键修复**：脚本原本默认覆盖输入文件，导致原始 95 条被抓取数据被截断成 Top 50，三问只能看到筛选后的。改为写入 `_scored.json`
- 触发器关键词从宽泛词（CPI/M1/出清）收窄到组合词（核心CPI/M1增速/产能出清），命中量从 14 篇降到 5 篇
- 实测：海尔智家 2 篇、赣锋锂业 2 篇、长江电力连续 1 天 0 命中；T4/T7 命中

### 第 4 项：归档机制（已写规则，未执行归档）
- 新增 `.agents/scripts/archive_scan.py`（只读体检）
- 关键认知：**Obsidian wikilink 按文件名匹配，不是路径**。所以命令行 `mv` 不会断链——前提是全库无重名
- 实测：库内 46 组同名文件（README×9、日期名×多处），归档这些必须用 Obsidian 界面移动
- 卡片 1194 张，被引用 ≤1 次的有 500 张（>180 天）——但「没连上」不等于「该退役」
- AGENTS.md 新增「归档规则」一节，含触发条件/动作/链接安全/检查清单

### 教训
- 改 skill 文件注意大小写：macOS 大小写不敏感，`skill.md` 和 `SKILL.md` 是同一文件，但 git 记录大小写
- 用 edit 工具替换大段内容时容易误删中间标题，改完要回头验证结构
