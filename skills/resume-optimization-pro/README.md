
在 Claude Code 中直接输入：

```
帮我优化这份简历：/path/to/resume.md

```

## ✨ 核心特性

### 8维度评分体系

| 维度 | 权重 | 评估内容 |
|------|------|----------|
| 信息准确性 | 15分 | 数据可验证性、信息一致性 |
| 结构合理性 | 15分 | 层次清晰、重点突出、篇幅适中 |
| 专业表达 | 15分 | 符合岗位级别、用词精准 |
| 框架应用 | 10分 | CAR/STAR/PAR/SOAR原则 |
| 量化数据 | 10分 | 业绩、规模、效率均量化 |
| 差异化竞争力 | 15分 | 独特价值主张清晰 |
| ATS友好度 | 10分 | 关键词覆盖、格式规范 |
| 细节完善度 | 10分 | 无冗余、无遗漏、无错误 |

**目标**：90+分优秀简历，可直接投递

### 迭代优化流程

```
读取简历 → 8维度评分 → 识别问题 → 提出建议 → 应用框架改写 → 重新评分
    ↑                                                              ↓
    └──────────────────── 循环迭代直到90+分 ──────────────────────┘
```

### 成就描述框架

| 框架 | 适用场景 |
|------|----------|
| CAR (Challenge-Action-Result) | 产品设计、技术决策、创新项目 |
| STAR (Situation-Task-Action-Result) | 项目经历、问题解决、团队管理 |
| PAR (Problem-Action-Result) | 问题解决、技术攻关、危机应对 |
| SOAR (Situation-Obstacle-Action-Result) | 克服困难、突破障碍 |

### 面试准备生成

简历优化到90+分后，自动生成：

- **4种场景自我介绍**：正式面试版、商务场合版、技术社区版、内部团队版
- **40+面试题库**：涵盖管理、技术、产品、战略、HR等8大类别
- **STAR法则完整回答**：基于简历真实内容生成

## 💡 v1.1 新增功能

### 总监级别语言转换

自动识别并转换语言风格：

❌ **工程师视角**：
```
精通React、Vue、Angular等主流前端框架
擅长组件开发、性能优化、工程化配置
```

✅ **总监视角**：
```
主导前端技术体系和标准化流程建设，覆盖组件库/工程化/性能优化全场景
推动工具链整合和自动化，具备技术决策、架构设计和团队管理能力
```

**转换原则**：强调"主导/推动/决策"而非"精通/擅长"，关注体系建设而非工具使用

### 个人vs公司成就区分

❌ **错误**：在公司工作经验中写个人公众号运营

✅ **正确**：个人品牌放联系方式，工作经验只写公司相关成就

### 荣誉奖项智能排序

基于6秒扫描法则，按 **级别 > 排名 > 时间** 排序，最高荣誉放第一位

### ATS系统优化

- 关键词精确匹配（包含缩写和全称）
- 标准章节标题、单栏布局
- 避免表格、图片、特殊格式
