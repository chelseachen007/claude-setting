| 项 | 接口 / 来源 | 说明 |

| 股价 / 市值 / 股本 | `push2.eastmoney.com/api/qt/stock/get` | 2026-11-11 收盘。`f116` 总市值、`f84` 总股本、`f85` 流通股本 |

## 二、PE 口径：踩过的坑与最终结论

### 最初的错误

用 `quote()` 拿到的 `f162` 标注为「PE25A 静态」。初稿据此写：「东山 PE(2025A) 24.9、源杰 64.4」。

**问题**：东山 2025 年归母净利 13.86 亿，总市值 1745 亿，**1745 / 13.86 = 125.9 倍**，不是 24.9 倍。差 5 倍。

### 中间的错误推理（已废弃，记录以免重犯）

看到差距后，我先猜测是「H 股增发导致股本口径差」——这个猜测**是错的**：股本从 18.32 亿变 19.45 亿（+6%），不可能造成 5 倍差异。

### 用反推法验证出的真相

拿东财返回的 `f162` / `f164` 除以 100，反推它们隐含的净利：

| 字段 | 东山 f162 = 24.75 | 隐含净利 = 1745/24.75 | 源杰 f162 = 63.94 | 隐含净利 = 873/63.94 |
|---|---|---|---|---|
| | | **70.51 亿** | | **13.65 亿** |
| 对比 | 2026Q1-3 净利 52.89 × 4/3 | **70.52 亿 ✅** | 10.24 × 4/3 | **13.65 亿 ✅** |

| 字段 | 东山 f164 = 32.01 | 隐含净利 | 源杰 f164 = 78.72 | 隐含净利 |
|---|---|---|---|---|
| | | **54.51 亿** | | **11.09 亿** |
| 对比 | 52.89 + 2025Q4(1.63) | **54.52 亿 ✅** | 10.24 + 1.45 | 11.69（差 0.6 亿） |

**结论：**

| 字段 | 真实含义 |
|---|---|
| **`f162`** | **2026 年前三季年化的 PE**（= 市值 ÷ (三季累计净利 × 4/3)） |
| **`f164`** | **TTM PE**（= 市值 ÷ (三季累计 + 上年Q4)） |

**都不是 2025A 静态 PE。** `fetch_eastmoney.py` 里把 f162 注释成「静态PE」是**命名不准确**，实际是年化口径。以后看到这个字段，先反推隐含净利再下结论。

### 真实的三套 PE（本文采用）

| 口径 | 东山精密 | 源杰科技 |
|---|---|---|
| **PE(2025A)** = 市值 ÷ 2025 年归母净利 | 1745.02 / 13.86 = **125.9** | 873 / 1.91 = **457.0** |
| **PE(TTM)** = 市值 ÷ (三季累计 + 上年全年 − 上年同期) | 1745.02 / 59.17 = **29.5** | 873 / 11.69 = **74.7** |
| **PE(2026E，Q4=Q3)** = 市值 ÷ (三季累计 + Q3 单季) | 1745.02 / 76.21 = **22.9** | 873 / 14.41 = **60.6** |
| **PE(2026E，×4/3)** = 市值 ÷ (三季累计 × 4/3) | 1745.02 / 70.52 = **24.7** | 873 / 13.65 = **63.9** |

> 2025A 的 PE 高得离谱（125.9 / 457.0），是因为两家 2026 年利润都翻了数倍（+332% / +867%）。**用 2025A PE 判断贵贱毫无意义**，研究.md 里保留这一行只是为了让读者知道「涨了多少」。

## 三、关键数字的计算过程

```
东山精密（A+H 全口径）
  总市值        1745.02 亿（f116）
  总股本        19.45 亿股（f84，2026-10-28 H 股发行后：A 18.32 + H 1.14）
  2026Q1-3 净利  52.89 亿   2025Q1-3 净利 12.23 亿（=52.89/4.3234）
  Q3 单季净利    23.32 亿   Q3 单季营收 175.82 亿
  2025 年净利    13.86 亿   2025 半年净利 7.58 亿
  TTM          = 52.89 + 13.86 − 7.58 = 59.17 亿
  2026E(Q4=Q3)  = 52.89 + 23.32 = 76.21 亿
  2026E(x4/3)   = 52.89 × 4/3 = 70.52 亿
  PB = 1745.02 / 权益 264.6 亿 = 6.58

源杰科技
  总市值        872.86 亿（f116）
  总股本        1.245 亿股（f84，2026-05 每 10 股转增 4.5 股后）
  2026Q1-3 净利  10.24 亿   2025Q1-3 净利 0.46 亿
  Q3 单季净利     4.17 亿（=10.24−6.07）
  2025 年净利     1.91 亿   2025 半年净利 0.46 亿
  TTM = 10.24 + 1.91 − 0.46 = 11.69 亿
  2026E(Q4=Q3) = 10.24 + 4.17 = 14.41 亿
  2026E(x4/3)  = 10.24 × 4/3 = 13.65 亿
  PB = 872.86 / 权益 35.0 亿 = 24.94
```

## 五、做了什么

1. `工具/抓数/fetch_eastmoney.py quote` 抓两家快照与 11 家同业。
2. 新建 `脚本/fetch_main.py`：拉 2021–2026 共 11 个报告期的营收/净利/毛利率/ROE/EPS/BPS → `数据/fin_main.json`。
3. 新建 `脚本/fetch_cf_bs.py`、`fetch_cf_bs2.py`：探测并抓现金流 + 资产负债 → `数据/cf_bs.json`。
   - **坑**：`RPT_DMSK_FN_CASHFLOW` 的 `END_CCE`（期末现金）返回 None，不可用。
4. 新建 `脚本/fetch_k.py`：500 根日线，算区间涨幅与最大回撤 → `数据/kline.json`。
5. 新建 `脚本/fetch_peers.py`：11 家同业估值 → `数据/peers.json`。
6. `web_search` 补齐业务与事件：索尔思并购对价与商誉、H 股发行细节、板块回调原因、源杰产能与客户指引。

## 六、没核实的地方

| 项 | 状态 | 影响 |
|---|---|---|
| 索尔思 2026 年单独营收/净利 | **未核原文**，只有「2025 年占合并净利 22.69%、2026Q1 占 52.92%」两个二手引用 | 「利润一半靠并表」据此推断 |
| 源杰前五大客户占比 | **没拿到数据** | 「客户集中度是隐患」只是定性判断 |
| S.5548 法案 / FCC 65% BOM | **二手券商点评**，未读原文 | 利空性质的判断可能被夸大或低估 |
| 源杰 23.6% / 3.1% 份额 | 灼识咨询，经新闻稿转述 | 「全球第二」的叙事基础 |
| H 股募资后负债率「约 55%」 | **我的估算**：89 亿人民币简单扣减总负债，未考虑资金用途分配 | 年报出来要复核 |
| 东山 2025 年报 EPS 0.79 | 与股本 18.32 亿对不上（13.86/18.32 = 0.757） | 可能是基本 EPS 用加权平均股本，未深究，不影响 TTM/2026E 计算 |
| 现金流 `END_CCE` | 东财返回 None | 只能算 OCF/资本开支，算不了「期末现金覆盖倍数」 |

## 七、给下次用的提醒

1. **看东财 PE 字段，先反推隐含净利**。`市值 ÷ (PE/100)` 与哪个利润口径吻合，就说明它是哪个口径。不要信字段名。
2. **H 股/转增股本后，市值要按 A+H 全口径**，否则 PE 会算错。
3. **4/3 年化与 Q4=Q3 年化要都给**，两者差 1.8 个点，对本例结论无影响，但写报告时标清楚口径比只给一个数更重要。
4. **两年前还在亏钱的公司**（源杰 2024A 净利 -0.06 亿）不能用「高增长」线性外推，必须回看它毛利率的完整波动区间（65%→43%→33%→82%）。
