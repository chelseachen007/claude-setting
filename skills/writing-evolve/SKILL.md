# 写作进化 — 从修改中学习

## 职责

本 Skill 分析人工修改与 AI 原稿之间的差异，提取可复用的修改模式，写入 `private/🧬 写作进化录.md`。下次写作时，`pang-writer` 会自动读取进化录中的活跃模式并应用。

## 触发条件

- 用户说"进化"/"写作进化"/"evolve"/"学习我的修改"/"分析我的改动"
- 用户提供了 AI 生成的原稿和自己修改后的终稿
- 用户想从改稿中沉淀写作规律

## 工作流

### Step 1：获取输入

接受以下任一形式的输入：
- 两个文件路径（AI 原稿 + 人工终稿）
- 直接粘贴的两段文本
- git diff（如果内容在版本控制中）

如果用户只给了一个文件（终稿），询问 AI 原稿在哪里。

### Step 2：逐段 Diff 分析

对比两个版本，逐段分析每次修改。将每个修改分类到以下类型中：

| 类型 | 标签 | 说明 |
|------|------|------|
| 词汇替换 | `word-swap` | 把一个词换成另一个（"震撼"→"愣住了"） |
| 节奏调整 | `rhythm` | 拆句、并句、段落重排 |
| 具体化 | `concrete` | 模糊描述→具体细节（"有一次"→"今天正在搞的"） |
| 情感调整 | `emotion` | 增加/删减情感表达 |
| 结构重组 | `structure` | 移动段落、改变行文顺序 |
| 工具名修正 | `tool-name` | 泛化名→具体名（"Claude"→"Claude Code + Clawbot"） |
| 口语化增加 | `colloquial` | 加入口头表达（"啥的"、"比很多人6"） |
| 删减 | `trim` | 去掉冗余、空泛过渡、AI 式结构 |
| 私人判断 | `judgment` | 加入"我觉得"、"我真的觉得"等立场表达 |
| 数字极端化 | `extreme` | 数字调整得更极端以增强冲击力 |

### Step 3：模式匹配

检查每个修改是否与 `private/🧬 写作进化录.md` 中「进化模式库」的已有模式匹配：
- 匹配已有模式 → 该模式观察次数 +1
- 新的修改类型 → 创建新条目写入「最近捕获」

### Step 4：写入进化录

将分析结果追加到 `private/🧬 写作进化录.md`：

**如果是已有模式的重复观察**：
- 更新该模式的观察次数
- 如果有新的之前/之后示例更有代表性，替换旧示例

**如果是新的修改类型**：
- 在「最近捕获」添加新条目，格式：
  ```
  ### YYYY-MM-DD：[修改类型标签]
  - **上下文**：[什么文章/什么场景]
  - **之前**：[AI 原文片段]
  - **之后**：[人工修改片段]
  - **分析**：[为什么改、改了什么效果]
  ```

### Step 5：整合建议

检查进化录中是否有模式达到升级/整合阈值：
- **观察 3 次** → 从「最近捕获」升级为「进化模式库」中的活跃模式
- **观察 5 次** → 建议整合进 `pang-writer` 风格指南，给出具体建议：应该在 pang-writer 的哪个部分加什么规则

### Step 6：输出报告

```
## 进化分析报告

**分析时间**：YYYY-MM-DD
**对比内容**：[文章/内容类型]

### 发现 N 处修改

| # | 类型 | 之前 | 之后 | 模式状态 |
|---|------|------|------|---------|
| 1 | 具体化 | "有一次..." | "今天正在搞的..." | 已有模式 +1 |
| 2 | 口语化 | "非常厉害" | "比很多人6" | 新发现 |

### 模式更新
- 模式「具体化」观察次数：3 → 4
- 新增捕获：口语化增加（1/3 升级）

### 整合建议
- 模式「xxx」已观察 5 次，建议整合进 pang-writer：[具体建议]

### 进化录已更新 ✅
```

## 防膨胀规则

- 「最近捕获」最多 20 条，超限时最旧条目：观察 ≥3 次的升级为模式，<3 次的丢弃
- 「进化模式库」最多 15 个活跃模式，整合进 pang-writer 后移至「已归档」
- 文件总活跃内容控制在 3000 字以内

## 与其他 Skill 的关系

- **pang-writer**：写作前读取进化录中的活跃模式并应用
- **content-diagnosis**：AI 味检测时参考进化录（进化录代表了人类明确选择不用的写法）
- **daily-learning-journal**：日复盘时如果发现有写作修改，建议调用本 Skill
