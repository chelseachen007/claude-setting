# 财报校对

核对个股财报数据的口径、数字和披露年份，产出「已核清 / 待核对」清单。依据 `投资研究/README.md` 的数据源与核对规范执行。

## 触发条件

用户说「财报校对」「校对财报」「核财报」「校对 XX 的财报」「查 XX 中报」等，或要求核对某只股票的业绩数据时触发。

## 核心原则

1. **关键数字回一手源**（巨潮公告原文），聚合源（雪球/AASTOCKS/同花顺）只用于定位，不直接采信。
2. **聚合源新闻标题不写年份**——必须点进原文看正文 `YYYY/MM/DD HH:MM CST` 时间戳确认归属年份，否则会把旧数据当新数据。
3. **口径统一后再比较**——不同口径的数字（股息率 vs 分红率、归母 vs 扣非、H 股纯利 vs A 股归母）直接对比会得出错误结论。
4. 核不死的项，如实标「待核对」，不硬下结论。

## 流程

1. **明确校对对象**：哪只股票、哪份财报（Q1/半年/全年）、要核哪些指标（净利/股息/营收/增速）。
2. **抓一手源**（加载 `web-access` skill）：按 `references/data-sources.md` 查巨潮公告是否披露 + AASTOCKS 原文确认披露日期。
3. **口径校对**：逐条过 `references/caliber-checklist.md`，识别并纠正口径混用。
4. **年份核实**：每个聚合源数字回溯其披露日期，确认是哪个财年的数据。
5. **产出报告**：区分「已核清」（附一手源证据）和「待核对」（标一手源 + 优先级）。

## 输出契约

校对报告写到 `投资研究/个股分析/YYYY-MM-DD-{标的}-财报校对.md`，结构：

```
## 已核清
（每项：结论 + 一手源证据 + 披露日期）

## 口径纠正
（每项：错误表述 → 正确口径 → 正确数值）

## 待核对清单
| # | 待核对项 | 一手源 | 优先级 |
```
