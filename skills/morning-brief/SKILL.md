# 写早报

只用当前目录里的东西，不联网，不编造。

1. 今天的早报是 `行思录/早报/YYYY-MM-DD.md`（年月日和当天一致，月份补零），目录不存在就先建。这个文件已经有了就不重写：第一行写“没事可做：今天的早报已经写过了”，结束。不要写 `行思录/日复盘/` 下的任何文件，那是日复盘的位置。
2. 看最近三天改过的文件：`find . -type f -mtime -3 -not -path './.git/*' -not -path './node_modules/*' -not -path './.obsidian/*' -not -path './.workbuddy-ai/*'`。目录是 git 仓库就再看 `git log --since=3.days --oneline`。
3. 什么新东西都没有：第一行写“没事可做：最近三天没有新内容”，结束，不写文件。
4. 写早报，三段，每段最多五条，每条一句话，写不出来的段就省略：
   - 最近发生了什么
   - 今天该做什么
   - 要留意什么
5. 最后一条消息的第一行写今天最重要的一件事，一句话，后面跟文件路径。这一行会发给用户，不要附回执。
