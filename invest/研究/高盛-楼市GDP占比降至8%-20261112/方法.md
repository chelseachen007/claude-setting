## 数据口径

| 项 | 口径 | 注意 |
|---|---|---|
| 营收/净利同比 | 东财 `RPT_LICO_FN_CPD`，**2026-09-30 累计（前三季）** | 不是单季。单季分化可能更剧烈 |
| 行业归属 | 东财 `BOARD_NAME` 前缀匹配（`房地产开发`、`房屋建设`、`水泥` 等） | 东财行业分类与申万不同，不可直接对比申万口径 |
| 净利中位数 | 含亏损股本位（负值参与 median） | 与加权同比差异大（见下） |
| 估值 | 东财 f43/f162/f167，÷100 还原 | PE25A = 2025 年报静态 PE |
| 资金流 | 东财 `fflow/daykline`，主力净额（超大单+大单） | 单位亿元 |
| 当日涨跌 | `daily_bars_adj` 最近两个交易日收盘价，**不复权对比** | 未剔除停牌、次新 |

## 已知接口问题（2026-11-12）

| 接口 | 症状 | 绕过方式 |
|---|---|---|
| `fetch_eastmoney.board_kline` / CLI `board` | 所有板块、所有周期都报 `Remote end closed connection without response` | 用数据湖 `daily_bars_adj` + `industry_members` 聚合 |
| `fetch_eastmoney.board_flow("水泥")` | 报 `'NoneType' object is not subscriptable`——**不是接口问题，是 `BOARDS` 内置表里没有「水泥」这个键**，中文名直接透传成 URL 参数被拒 | 水泥正确代码 **BK0424**、银行Ⅱ **BK0475**（不是 BK0712）。详见 `知识库/东方财富接口备忘.md` 二.8 |
| duckdb `industry_members` 东财分类覆盖不全 | `industry_code='451'`（房地产开发 L3）只含 10 只，实际全行业 89 家 | 用 L2 代码（`1202` 房地产 66 只、`1209` 建筑装饰 42 只）或按行业名匹配 |
| duckdb 时间戳字段 | 直接 select 带 `TIMESTAMP WITH TIME ZONE` 的列会报 `No module named 'pytz'` | 在 SQL 里 `cast(... as varchar)` 或只 select 非时间列 |

## 关键计算说明

**为什么要算中位数而不是按市值加权**

`scan_re_vs_others.py` 输出了加权口径，结果明显失真：
- 地产链 `profit_weighted` = +4.0%，但中位数 **-13.4%**
- 非地产链 `profit_weighted` = +434.9%，明显是个别巨亏/巨盈公司拖动

原因：东财 `SJLTZ` 是**同比增速**，加权用的是**当前归母净利**，对低基数暴增的公司严重放大（如万科同比 +14.5% 但归母 -239 亿）。所以正文一律用**中位数**。

## 哪几条没核实

1. 高盛原始英文报告标题、作者、页码：**未确认**（AAStocks 未给出标题）
2. 「18 城调研」「27 个月有效库存」：所有引述均指向自媒体（海之岚、QQ阅读、club-qyh），**没有 HK 正规媒体一手引述**。KC桌面的英文标题说明存在这么一份报告，但数据是否如自媒体所述未验证
3. 「2025-2035 土地出让量跌九成」：AAStocks 原文是「2025至2035年住宅土地出讓量料跌逾九成」，**注意主语是「住宅土地出让量」不是「全部土地出让金」**。自媒体把它写成「土地出让金从 1.66 万亿降到 400 亿」——后者是另一篇（9-18 展望篇）的推测数字，两个不是一回事
4. 杭州本地土地财政依赖度：**未查**
5. 2026 全年 GDP 数据：**尚未发布**（2027 年 1 月出），无法验证 1.8pp 拖累
