# 方法.md

## 筛选流程
1. 全市场快照 → 按市值/行业初筛 → `数据/screen_base.json`
2. 按三个方向（高股息/消费/医疗）分别打分 → `数据/pick_*.json`
3. 人工复核 + 财报验证 → `数据/final_*.json`
4. 成文 → `研究.md`

## ⚠️ 脚本不可复现
`脚本/screen3.py` 依赖 `universe_raw.json`、`div_all.json`、`bvps.json`、`base3.json` 四个中间文件，
**这四个文件在 2026-11-11 整理时已不存在**（原在 `scratch/`，未随迁移保留）。
- 影响：脚本无法直接重跑，只能读 `数据/` 里的成品 JSON
- 如果以后要重跑：先补齐这四个取数步骤，或者改用 `工具/抓数/fetch_eastmoney.py`

## 口径
- 股息率 = 按最近完整会计年度（2025 年报）归集的静态股息率，不是 TTM
- PE/PB 口径见正文
