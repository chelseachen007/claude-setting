# Daily Learning Journal 使用说明

## 概述

自动总结每日的 Claude Code 会话记录，提取学习知识点和未完成事项，记录到 Obsidian 行思录。**周五自动切换为周复盘模式。**

## 目录结构

```
行思录/
├── 日复盘/
│   └── 2026/
│       ├── 2026-03/
│       │   └── 2026-03-30.md
│       └── 2026-04/
│           └── 2026-04-02.md
├── 周复盘/
│   └── 2026/
│       └── 2026-04/
│           └── W-2026-04-04.md
└── review-log.md
```

## 使用方法

在 Claude Code 中说：

- "总结今天的学习" → 日复盘
- "写今天的日记" → 日复盘
- "周复盘" → 强制周复盘
- 周五说"总结今天的学习" → 自动切换周复盘

## 模式检测

- 周五（`date +%u` = 5）→ 自动进入周复盘模式
- 其他日期 → 日复盘模式
- 用户可手动指定模式覆盖自动检测

## 特性

✅ **周五自动周复盘**：检测到周五自动切换模式
✅ **面包屑学习法**：日复盘记录学习路径，周复盘中串联
✅ **双数据源周复盘**：本周会话文件 + 已有日复盘
✅ **自动创建目录**：按照年/月自动创建目录结构
✅ **标准格式**：使用 Obsidian frontmatter 和 Markdown 格式

## 文件位置

- Skill 定义：`.agents/skills/daily-learning-journal/SKILL.md`
- 日复盘目录：`行思录/日复盘/`
- 周复盘目录：`行思录/周复盘/`
