# 反模式：常青笔记变成文章总结

## 症状（Symptom）

常青笔记章节出现"文章认为..."、"作者提出..."、"本文总结..."等复述性语句，本质是换了个形式的文章摘要，不是独立的洞见。

用户看到的现象：
- 常青笔记读起来像文章摘要
- 删除文章后，常青笔记失去意义
- 没有新的认知增量

## 反模式（Anti-Pattern）

AI 没有理解"常青笔记"的定义——应该是"不管这篇文章存不存在，这个认知都有价值"。

错误做法：
1. 提取文章观点
2. 重新措辞
3. 当作常青笔记

正确做法：
1. 理解文章核心概念
2. 提炼独立命题
3. 验证：删除文章后，这个认知是否仍有意义？

## 为什么失败（Why It Fails）

### 根因分析

1. **没有理解"常青"的定义**
   - AI 把"常青笔记"理解为"文章要点"
   - 没有区分"这篇文章说了什么"和"这个认知本身有什么价值"

2. **缺乏独立性检验**
   - 没有检验方法：删除文章后，常青笔记是否仍有意义？
   - 没有检验标准：什么是"独立命题"？

3. **生成逻辑过于简单**
   - 直接从文章提取观点
   - 没有经过"去语境化"处理

4. **训练数据偏差**
   - 大量训练数据是摘要式的笔记
   - AI 学会了"总结文章"的模式

## 修复方案（Fix）

### 1. 在 SKILL.md 中明确定义

在 Step 6b 添加：

```markdown
#### 常青笔记（1-3 条）
- 从文章中提炼的持久洞见
- 每条是一个独立的、面向未来的知识点
- 格式：小标题 + 2-3 句解释
- 不是总结文章，而是提炼"不管这篇文章存不存在，这个认知都有价值"的东西
- **检验方法**：删除文章后，常青笔记是否仍有意义？
- **禁止**：使用"文章认为"、"作者提出"、"本文总结"等主语
```

### 2. 实现检验逻辑

```python
def validate_evergreen_note(note, article_content):
    """验证常青笔记是否独立"""

    # 禁止的主语
    forbidden_subjects = [
        "文章", "作者", "本文", "这篇", "原文",
        "article", "author", "this paper"
    ]

    for subject in forbidden_subjects:
        if subject in note:
            return False, f"常青笔记不应依赖文章存在：包含'{subject}'"

    # 检查是否是独立命题
    # 简单启发：删除文章后，常青笔记是否仍有意义？
    if is_dependent_on_article(note, article_content):
        return False, "常青笔记依赖文章上下文"

    return True, "OK"

def is_dependent_on_article(note, article):
    """判断常青笔记是否依赖文章"""
    # 提取文章中的独特术语
    article_terms = extract_unique_terms(article)

    # 常青笔记中引用了多少文章独特术语？
    note_terms = extract_terms(note)
    overlap = note_terms & article_terms

    # 如果引用了 >50% 的文章独特术语，可能依赖文章
    if len(overlap) / len(article_terms) > 0.5:
        return True

    return False
```

### 3. 生成时强制去语境化

```python
def generate_evergreen_note(article_insight):
    """生成常青笔记（去语境化）"""

    # Step 1: 提取文章核心洞见
    insight = article_insight

    # Step 2: 去语境化
    # 移除文章特定的引用
    decontextualized = remove_article_references(insight)

    # Step 3: 提升为独立命题
    # 从"这篇文章说了X"提升为"X本身有价值"
    independent = elevate_to_independent命题(decontextualized)

    # Step 4: 验证独立性
    is_valid, reason = validate_evergreen_note(independent, insight)
    if not is_valid:
        # 重新生成
        return regenerate_with_constraint(insight, reason)

    return independent
```
